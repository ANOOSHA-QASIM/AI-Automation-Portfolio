# Anusha Qasim — Portfolio

Personal portfolio built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## Positioning
AI Automation Engineer | Agentic AI | Founder & CEO, XORA

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

## Production checks

```bash
npm run lint
npm run build
```
